# Tool scout 2026-11-22

4 licence-safe candidates checked; model: gemini-3.6-flash.

## [microsoft/Aion-1.0-Instruct-2.3B](https://huggingface.co/microsoft/Aion-1.0-Instruct-2.3B)
- For: Orbitwire and Kyun Hua - local CPU script drafting and hook generation
- Why: At 2.3B parameters, it runs extremely fast on 4 vCPU GitHub Actions runners with low RAM overhead compared to Gemma 12B/27B, enabling rapid structured script drafting and pre-filtering directly in build pipelines without external API latency.
- Test: Run inference on a 4 vCPU GitHub Actions runner with llama.cpp to generate a 30-second news script outline; measure tokens per second and JSON schema adherence.
- Risk: Small model size (2.3B) carries higher risk of factual hallucinations; must be restricted to structural drafting and hook variation rather than unverified fact generation.

## [Reson8/Rumble-2-Flash](https://huggingface.co/Reson8/Rumble-2-Flash)
- For: Atlas in Numbers and Kahaani Chaos - fast karaoke caption alignment
- Why: Updated recently (October 2026) and designed for ultra-fast speech recognition, potentially reducing render pipeline bottleneck on Modal/CPU runners for sub-second precise word-level subtitle alignment.
- Test: Align a 60-second audio track against its transcript on a CPU runner; compare word-boundary timestamp precision and execution time against faster-whisper.
- Risk: May have lower precision on accented or stylized voiceovers (e.g., character voices or Hindi-English code-switching) compared to Whisper.

## [ggerganov/whisper.cpp](https://huggingface.co/ggerganov/whisper.cpp)
- For: All Shorts channels - zero-dependency standalone CPU subtitle timestamping
- Why: Compiles to a lightweight native binary with zero Python runtime overhead, drastically cutting execution time and RAM usage on GitHub Actions runners when generating alignment for karaoke captions.
- Test: Execute whisper.cpp binary with quantized GGML model on a 30-second narration file within a 4 vCPU Linux runner; compare RAM consumption and execution speed against faster-whisper Python library.
- Risk: Requires GGML quantized model binaries; core HuggingFace repo mirror hasn't been updated recently relative to active upstream GitHub repo.

## [OVHaiLLM/Olala-v1.0-mini-7A1B](https://huggingface.co/OVHaiLLM/Olala-v1.0-mini-7A1B)
- For: Pangaea Nights and Scam Autopsy - long-form script structure and outline expansion on CPU
- Why: Offers an alternative compact architecture designed to deliver stronger long-context reasoning for documentary outlines while remaining lightweight enough to evaluate on CPU runners.
- Test: Generate a multi-section documentary outline from research notes on CPU; benchmark token output speed and narrative coherence.
- Risk: Niche model with limited community adoption; needs verification for GGUF/llama.cpp compatibility before pipeline integration.
