# Tool scout 2026-10-21

15 licence-safe candidates checked; model: gemini-3.8-flash.

## [inclusionAI/Ming-3.0-tts-0.5B](https://huggingface.co/inclusionAI/Ming-3.0-tts-0.5B)
- For: Kahaani Chaos and Kyun Hua - Hindi emotional narration
- Why: Provides an expressive, local Hindi/English TTS alternative to Gemini API quotas. At 0.5B parameters, it fits easily in 16 GB RAM on a 4-vCPU runner, preventing repetitive voice signatures that trigger human review refusals for inauthentic content.
- Test: Run inference on a 45-second Hindi mystery script snippet on a local CPU/GitHub Actions environment; measure RTF (real-time factor) and evaluate emotional inflection against Gemini Sulafat.
- Risk: MIT license is commercial-friendly. May require PyTorch dependency management on GHA and could be slower than cloud API calls if quantization isn't supported out-of-the-box.

## [gradium/phonon-31m-en](https://huggingface.co/gradium/phonon-31m-en)
- For: Orbitwire and Pangaea Nights - English narration & scratch audio
- Why: Ultra-lightweight 31M parameter English TTS that runs near-instantaneously on a 4-vCPU runner. Reduces GitHub Actions workflow duration and eliminates external API failure points for high-frequency English news shorts.
- Test: Benchmark a 60-second Orbitwire news script on an Ubuntu runner with 4 vCPUs; check speech naturalness, memory footprint (<1 GB RAM), and whether generation finishes in under 5 seconds.
- Risk: Apache-2.0 license is safe. 31M model size may lack natural prosody or emotional nuance compared to Kokoro-82M on complex narrative sentences.

## [OpenMOSS-Team/MOSS-SoundEffect-v2.0](https://huggingface.co/OpenMOSS-Team/MOSS-SoundEffect-v2.0)
- For: Kahaani Chaos, Orbitwire, and Scam Autopsy - automated bespoke Foley & sound design
- Why: YPP human review strictly penalizes generic, template filler. Generating scene-matched sound effects dynamically from beat prompts significantly increases production originality and viewer retention (watch time lever).
- Test: Deploy a lightweight Modal serverless endpoint to generate 3 custom SFX (e.g., 'creaking ancient temple door', 'subtle dramatic drone') from text prompts and verify output quality and latency.
- Risk: Apache-2.0 license. Too compute-heavy for 4-vCPU GitHub Actions runners, so it must run on Modal free credits; requires fallback if prompt adheres poorly to duration bounds.

## [qualcomm/Depth-Anything-V2](https://huggingface.co/qualcomm/Depth-Anything-V2)
- For: Orbitwire and Kyun Hua - parallax 2.5D photo depth maps
- Why: Hardware/CPU-optimized export of Depth-Anything-V2 that reduces latency and CPU cycles per frame compared to unoptimized Hugging Face transformers, shortening parallax build times on GitHub Actions.
- Test: Process 5 standard Commons editorial images on a 4-vCPU machine using the Qualcomm runtime (ONNX/TFLite) against transformers Depth-Anything-V2-Small; compare inference seconds per image and visual depth boundary fidelity.
- Risk: MIT license is safe. Ensure the Qualcomm runtime bundle does not require proprietary Snapdragon-specific NPU dependencies and runs cleanly on generic x86_64 CPU Linux runners.

## [inclusionAI/Ming-3.0-asr-tiny](https://huggingface.co/inclusionAI/Ming-3.0-asr-tiny)
- For: Kyun Hua and Mool Katha - karaoke caption word-level timestamp alignment
- Why: A tiny ASR footprint designed for rapid transcription and alignment. Relieves CPU load during the render step compared to Whisper, speeding up the publishing pipeline for trending news shorts where timing is the #1 reach driver.
- Test: Align a 30-second rapid Hindi TTS audio sample; compare word-boundary accuracy against faster-whisper and measure CPU execution time.
- Risk: MIT license. Accuracy on colloquial Hinglish or complex Hindi scripture terminology in Mool Katha may drop compared to larger Whisper models.
