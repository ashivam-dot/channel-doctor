# Tool scout 2026-10-10

42 licence-safe candidates checked; model: gemini-3.8-flash.

## [hexgrad/Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M)
- For: Orbitwire and Scam Autopsy: English voiceover narration
- Why: At only 82M parameters, it delivers near-commercial voice naturalness and emotion while running faster than real-time on a standard 4 vCPU runner without a GPU.
- Test: Synthesize a 200-word investigative script on a 4 vCPU GitHub Actions runner using kokoro-onnx; assert total generation time is under 15 seconds and audio has no robotic clipping.
- Risk: Apache-2.0 is monetization-safe; emotion control relies on text formatting and punctuation rather than fine-grained expressive style vectors.

## [fabiotosi92/ZipDepth](https://github.com/fabiotosi92/ZipDepth)
- For: Kyun Hua and Orbitwire: Photo parallax depth map generation
- Why: With only 6.1M parameters, it provides zero-shot monocular depth specifically engineered for edge/CPU devices, dramatically cutting render time on GitHub Actions runners compared to diffusion or heavy ViT architectures.
- Test: Pass 10 Commons JPEG stills through the inference script on 4 vCPU; verify inference completes under 1 second per image with clean edge separation for 2.5D parallax displacement.
- Risk: MIT license is safe; newly published repository requires checking pip dependencies and setup script stability for headless CI runners.

## [onnx-community/depth-anything-v2-small](https://huggingface.co/onnx-community/depth-anything-v2-small)
- For: Kyun Hua and Orbitwire: Production fall-back depth estimation
- Why: Pre-exported ONNX format integrates directly with onnxruntime-cpu, removing heavy PyTorch dependencies in the CI workflow while retaining Depth Anything V2's robust boundary handling.
- Test: Load model into onnxruntime on CPU and run depth estimation on 5 test news images; check that memory footprint stays well below 1 GB RAM during batch processing.
- Risk: Apache-2.0 is safe; small variant can occasionally struggle with thin foreground objects like wires or antennae.

## [openai/whisper-large-v3-turbo](https://huggingface.co/openai/whisper-large-v3-turbo)
- For: Kyun Hua, Orbitwire, and Mool Katha: Word-level alignment for karaoke captions
- Why: Substantially faster inference than standard large-v3 while retaining multilingual accuracy across English and Hindi; runs cleanly on 4 vCPU via faster-whisper in int8 quantization.
- Test: Run faster-whisper int8 on a 60-second mixed Hindi/English Shorts audio sample; confirm word timestamp accuracy against spoken beats in under 10 seconds of processing time.
- Risk: MIT license is commercial-friendly; full precision requires significant RAM, so int8 or CTranslate2 quantization is strictly required on 4 vCPU runners.

## [ace-step/ACE-Step-1.5](https://github.com/ace-step/ACE-Step-1.5)
- For: Pangaea Nights: Ambient sleep score loop generation (run on Mac or Modal)
- Why: Permissive MIT license and explicit local hardware support (Mac Metal and Modal GPU) allow generating custom, copyright-free ambient drone and calm sleep scores without recurring subscription fees.
- Test: Execute a test generation script on Mac or a one-off Modal runner using a prompt like 'deep calm ambient drone C minor slow sleep'; generate 60 seconds and evaluate seamless loopability.
- Risk: MIT license is safe; too heavy for a pure 4 vCPU CI runner, so generation must happen locally on Mac or via Modal free credits and pushed as assets.
